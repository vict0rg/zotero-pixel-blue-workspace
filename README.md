# Zotero Pixel-Blue Workspace

Tema visual experimental para Zotero, inspirado no [pixel-blue Workspace de Rinrinsu](https://github.com/Rinrinsu/pixel-blue-workspace), com referências técnicas ao [Warm Theme for Zotero](https://github.com/YufeiXIA/zotero-warm-theme) e ao [Cupertino for Zotero](https://github.com/shenghuang-123/cupertino-for-zotero).

**Versão:** 0.1.1. O código-fonte completo e o pacote instalável `.xpi` serão publicados neste repositório. A faixa de compatibilidade declarada é Zotero 7 a 10; Zotero 11 beta é experimental.
